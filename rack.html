Rack targets

Everything in Rack targets is registered with the drive, so it can be routed from audio, LFOs or MIDI in the panel above — layer opacities included. Routing an LFO to two layer opacities is how you get a hands-free crossfade between tools.
The rack needs to be served over http, not opened as a file. Browsers treat file:// pages as cross-origin, so the rack can't reach into the tool frames to capture or drive them. Run a local server in the repo folder — python -m http.server — and open http://localhost:8000/rack.html, or use the GitHub Pages URL.
