Density
Direction uses normal optical flow — strokes get pushed the way things actually moved, not just excited where they moved. The density map is the composition — it decides where agents exist before a single line is drawn. Switch View to see it.
Seeding
Blue-noise spacing scales with density, so tone is carried by how close the marks sit — not by line weight. Turnover replaces resting agents; set it to 0 for a plate that converges.
Cycle
Continuous · Frames are layered on top of one another while the start/end pairs below sweep across the run. The same seed reproduces a plate exactly.
Start → end pairs
The end values are the ordinary sliders elsewhere in the panel — Speed and Wander in Motion, Width and Opacity in Ink. Scatter is chaos layered on top of the field.
Motion
Momentum is what makes a line look drawn rather than traced — with drag low, agents overshoot and cut corners instead of hugging the gradient.
Fluid
A real velocity field, kept divergence-free, that carries the agents. Movement pushes it, edge tangents stir it, and vorticity restores the swirl the solver would otherwise lose. Dissipation is how quickly the water goes still — set it near 0 and a gesture keeps circulating long after it ended.
Flocking
Separation is what keeps the line clean — agents refuse to redraw a contour a neighbour already drew.
Depth & time
In slice mode a stroke keeps the depth of the moment it was born. Successive moments nest inward, so a moving subject builds a solid from its own history.
Mark
With a shape chosen the agent stops drawing a continuous line and drops marks along its path instead — the mark becomes the unit rather than the trajectory. Size range gives each agent its own multiplier, so a population varies. Colour offset samples the image near the agent rather than exactly under it.

Flow field colours a stroke by the very noise that steers it, so hue follows form. Repeat above 1 cycles the palette across the range, which bands the result into contours. Opacity
Velocity at −1 makes fast strokes thin and slow ones heavy, which is how a loaded brush behaves. Nib mimics a chisel tip: strokes across the nib angle are broad, along it are hairlines. Set every value to 0 for uniform ligne-claire weight.
Colour
Steering stretches the Kuwahara kernel along the same edge directions the strokes follow. At 0 it is a plain square filter — flick between them to see the smear line up with the ink.
Dye is colour carried by the fluid rather than blurred — flat regions pull out into long smooth gradients. Needs the fluid enabled to move.
Bleed drags the ink layer along the same edge directions and stains the colour beneath. The crisp strokes stay on top, so you get the smear without losing the line.
Bloom is applied after the Kuwahara so the glow smears along the structure directions. Wash fades it toward the paper colour.
Audio & modulation
On the beat
A band tells you how loud something is; a beat tells you the moment it arrived. Onsets are detected against the band's own recent average, so the threshold holds across tracks. Respawn all agents is the flow reset — every agent relaunches on the hit, restarting the gesture without losing what is already on the canvas.
